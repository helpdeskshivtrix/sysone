Browser Sandbox vs. Native Companion Architecture

Why are certain metrics simulated?
Under W3C and browser security specifications, standard web applications run in a strict sandbox. Web browsers intentionally do not permit JavaScript to directly read hardware kernel MSR registers, monitor low-level CPU voltages/fan tachometers, or silently inspect raw hard drive contents.

What runs natively right now in ShivTrix Core:
• navigator.hardwareConcurrency: Physical/logical CPU core count
• navigator.deviceMemory: System RAM capacity tier
• navigator.connection: Network link speed and round-trip time
• navigator.storage.estimate(): Allocated browser storage capacity
• WebCrypto (crypto.subtle): Real hardware-accelerated cryptographic SHA hashing
• Web Audio API: Real-time procedural music synthesis and 10-band graphic DSP equalization

The ShivTrix Native Companion Daemon:
For bare-metal thermal monitoring, Windows Defender status, and full OS process control, users can optionally run the companion daemon (a lightweight local background service in Rust/Go that broadcasts to ws://localhost:9871).
